# kerux Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build kerux 0.1.0, a minimal, fully typed, async-first in-process mediator for Python, ready to publish on PyPI.

**Architecture:** A shared `Registry` base class holds request handlers, notification handlers and behaviors. `Mediator` (async) and `SyncMediator` subclass it and differ only in dispatch and in rejecting async callables. Handlers are stored as entries that are either a ready handler or a zero-argument factory, resolved lazily when the pipeline reaches them.

**Tech Stack:** Python 3.11+, uv, hatchling, pytest + pytest-asyncio, ruff, mypy (strict), pyright (strict), GitHub Actions, PyPI Trusted Publishing.

**Spec:** `docs/superpowers/specs/2026-10-16-kerux-design.md`

## Global Constraints

- Python `>=3.11`; use `typing.Generic`/`TypeVar`, not PEP 695 syntax.
- Zero runtime dependencies.
- `mypy --strict` and pyright `strict` pass on `src/` and `tests/typing_checks.py`.
- Package version `0.1.0`, MIT license, ships `py.typed`.
- Public names: `Request`, `Notification`, `Mediator`, `SyncMediator`, `KeruxError`, `HandlerNotFoundError`, `HandlerAlreadyRegisteredError`.

## Review Focus

1. An object whose `handle` method is `async`, registered on `SyncMediator`, is rejected with `TypeError` at registration (test in Task 3).
2. A behavior that never calls `next` means the handler factory is never called (test in Task 2).
3. An exception raised by a handler propagates unchanged through behaviors (test in Task 2).
4. `@mediator.handler` on a function using `from __future__ import annotations` resolves the string annotation; a missing annotation or a non-`Request` annotation raises `TypeError` (test in Task 1).
5. Sending an instance of a *subclass* of a registered request type raises `HandlerNotFoundError` (exact-type dispatch; test in Task 2).

  - `class Mediator(Registry)`
  - `async def send(self, request: Request[R]) -> R`
  - `async def publish(self, notification: Notification) -> None`
  - Handler call rule: use `obj.handle(x)` if present, else `obj(x)`. Await the result if `inspect.isawaitable`. This rule is shared, so put it in `_registry.py` as `_invoke(obj, *args)`.

- [ ] **Step 1:** Write `tests/test_mediator.py`:

  - `HandlerNotFoundError` for an unregistered type and for a subclass of a registered type (Review Focus 5).
  - Behaviors run in order: outer before, inner before, handler, inner after, outer after.
  - A sync behavior works in the async mediator.
  - A behavior with `request_type=` is skipped for non-matching requests.
  - A short-circuiting behavior means the factory is never called; the factory raises if it is called (Review Focus 2).
  - A handler exception propagates through behaviors unchanged; assert it's the same exception object (Review Focus 3).
  - Behaviors apply to `Request[None]`.
  - publish calls handlers in registration order.
  - publish with no handlers is a no-op.
  - publish stops at the first failing handler.

### Task 3: `SyncMediator`

**Files:**
- Create: `src/kerux/_sync_mediator.py`
- Modify: `src/kerux/__init__.py`
- Test: `tests/test_sync_mediator.py`

**Interfaces:**
- Produces:
  - `class SyncMediator(Registry)` with `def send(self, request: Request[R]) -> R` and `def publish(self, notification: Notification) -> None`.
  - Overrides `_validate` to raise `TypeError` when `_is_async(obj)` is true. `_is_async` uses `inspect.iscoroutinefunction` on the object, on its `handle` and on its `__call__`.
  - At call time, an awaitable result is closed (if it is a coroutine) and raises `TypeError`. A factory's product is validated when created.

- [ ] **Step 1:** Write `tests/test_sync_mediator.py`:
  - send, `Request[None]`, behaviors order, short-circuit and publish (mirroring Task 2 in sync form).
  - Rejecting at registration: an async function, an object with async `handle` (Review Focus 1), an object with async `__call__`, a `functools.partial` of an async function, an async behavior.
  - A lambda returning a coroutine raises `TypeError` at send, with no "never awaited" warning (use `pytest.warns` absence / `filterwarnings = error`).
  - A factory producing an async handler raises `TypeError` at send.
- [ ] **Step 2:** Run `uv run pytest tests/test_sync_mediator.py`. Expected: FAIL.
